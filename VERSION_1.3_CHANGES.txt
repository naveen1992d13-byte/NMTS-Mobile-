SLEEPING STOCK MOBILE 1.3.0 (versionCode 6)

1. Auto Perpetual physical verification
   - Tap assigned part → compact verification modal
   - Local SQLite save is instant; UI shows Verified / Physical Qty / status
   - Progress: Verified N / Total, Pending
   - Sticky "Submit Verified Parts (N)" triggers background/batch sync

2. Faster offline sync
   - Prefer POST /mobile/stock-verification/batch
   - Fallback: parallel chunk sync (8 at a time)
   - Non-blocking "Syncing N..." / "✓ Synced" banner
   - Auth token cache avoids repeated SecureStore lookups

3. Payload integrity
   - verification_type and damage_qty preserved queue → API

4. Stock Availability UX
   - Search input moved to top with keyboard-safe layout
   - Product Hub style prefix/description search
   - Aging threshold (default 90d) with value-only highlight
   - Dedicated Multiple Part Search (Found / Not Found)

5. Notifications
   - Listeners registered once per device session (not per screen change)
   - Snooze / Skip / Pick preserved

6. Android back
   - Scanner/detail → previous screen
   - Home/Pair allow normal Android exit (no trap)

7. Mandatory update
   - Blocks app usage when server marks update mandatory

8. Session consistency
   - Backend IST daily session is authoritative (AOPS/MOPS)
   - No client-invented per-part session IDs
